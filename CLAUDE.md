# Lernquest – notes for Claude

German educational roguelike for primary-school children (about 3rd grade). Read README.md first.

## Always keep the changelog up to date

**Every change a player or parent can notice must get an entry in `CHANGELOG.md` in the same commit.**

- No version numbers – entries are grouped by date: `## JJJJ-MM-TT` (newest first, each date only once).
  Add to today's heading if it exists, otherwise create it at the top.
- Under the date use only these groups, in this order: `### Neu`, `### Verbessert`, `### Behoben`.
- One `- ` line per point: a short German sentence a child or parent understands
  (no technical terms like "localStorage", "Service Worker", "CI").
- Purely internal changes (tests, CI, refactoring) don't need an entry.
- The file is shown in the game ("Was ist neu?" on the title screen): `build.py` parses it, so keep the format
  exactly as described in the file header and run `npm run build` afterwards. The build fails if dates are out of order.

## Workflow

- Edit `src/*`, never `docs/index.html`, `docs/sw.js` or `docs/manifest.webmanifest` by hand – they are generated by
  `npm run build`. Commit `docs/` together with `src/`; CI fails if `docs/` doesn't match `src/`.
- Before committing: `npm run build && npm test && npm run playtest`.
- Icons and iOS launch screens (`docs/icons/`, `docs/splash/`) come from `node tools/make_icons.js`
  (needs Playwright); only rerun it when the artwork changes.
- GitHub Pages serves `docs/` from `main`: https://thezieger.github.io/rogue-adventures/

## Conventions

- All player-facing text is German, child-friendly, with German typography („…“, –).
- No time pressure, no comma numbers in what children see (show whole numbers).
- No external requests at runtime (fonts are self-hosted in `docs/fonts/`), no tracking, everything stays on the device.
  Only exception: the feedback screen posts the message to the Google Form when the player taps „Absenden“.
- The app is an installable PWA: assets the game needs offline must be listed in `CORE` in `src/sw.js`.
- Learning content follows the class worksheets – check factual changes to `src/knowledge.js` carefully.
