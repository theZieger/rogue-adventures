# Lernquest on the App Store

The iOS app is a [Capacitor](https://capacitorjs.com) shell: a native app with a web view that shows the built game
from `../docs`, bundled inside the app. It works offline from the first start and makes no requests except the
feedback form. Unlike the Android app (which shows the live website), **every game update needs a new build and
review**: run the „ios-app“ workflow after merging to `main`, then submit the build in App Store Connect.

| File | Purpose |
|---|---|
| `capacitor.config.json`, `package.json` | App ID `io.github.thezieger.lernquest` (same as Android; can't change after the first upload), name, web folder |
| `xcode/App/` | Xcode project. `App/public` (the copied game) is generated by `npx cap sync ios` and not committed |
| `xcode/App/App/Assets.xcassets/` | App icon (1024, opaque) and launch image, from `node tools/make_icons.js store` |
| `store/screenshots/` | App Store screenshots, iPhone 6.9″ (1320×2868) and iPad 13″ (2064×2752), same command |
| `../.github/workflows/ios.yml` | Builds, signs and uploads to TestFlight on a GitHub macOS runner – no Mac needed |

Local build on a Mac (optional): `cd ios && npm ci && npx cap sync ios && npx cap open ios`, then Run in Xcode.

## One-time setup

1. **Apple Developer Program**: https://developer.apple.com/programs/ – 99 USD/year. As a person or as an
   organisation (needs a D-U-N-S number). The name appears as the seller in the App Store. EU: App Store Connect asks
   for trader status (DSA); a trader's address, phone and e-mail are shown publicly.
2. **Create the app** in App Store Connect → Apps → „+“: platform iOS, name „Lernquest“ (must be free in the store),
   primary language German, bundle ID `io.github.thezieger.lernquest` (register it first under Certificates,
   Identifiers & Profiles → Identifiers if it isn't offered), SKU e.g. `lernquest`.
3. **API key for the workflow**: App Store Connect → Users and Access → Integrations → App Store Connect API →
   Team Keys → „+“, access **Admin** (needed so Xcode may create the distribution certificate). Download the `.p8`
   (only possible once). Repository → Settings → Secrets and variables → Actions:
   - `ASC_KEY_ID` – the key ID, `ASC_ISSUER_ID` – the issuer ID shown above the key list
   - `ASC_KEY_P8_BASE64` – `base64 -i AuthKey_XXXX.p8` (macOS) / `base64 -w0 AuthKey_XXXX.p8` (Linux)
   - `APPLE_TEAM_ID` – Membership details → Team ID
4. **Build**: Actions → „ios-app“ → „Run workflow“. The build appears under TestFlight after Apple's processing
   (10–30 minutes). Version = date (`2026.11.11`), build number = run number.
5. **TestFlight**: add yourself and testers (internal testers need no review), test on a real iPhone and iPad.
6. **Submit**: fill in the listing below, pick the build, „Add for Review“. Review usually takes 1–3 days.

The workflow uses the `macos-26` runner (Xcode 26 / iOS 26 SDK, which App Store uploads require). If GitHub has
moved on, change `runs-on` to the current macOS image. Capacitor updates: bump the three `@capacitor/*` versions in
`package.json`, `npm install`, `npx cap sync ios`, commit.

## App Store Connect answers

**App information**
- Category: **Education** (secondary: Games → Educational or Family). Recommendation: **don't** pick the Kids Category.
  Kids Category apps must put every link that leaves the app and every purchase behind a parental gate that a child
  can't pass; Lernquest's parents' area only has a PIN if the parents set one, and the privacy page links out.
  Outside the Kids Category the app can still be clearly made for children (age rating 4+).
- Age rating questionnaire: the only question that matters is „Cartoon or Fantasy Violence“ (monster battles: a hit
  only lowers a bar, no blood, nothing gets hurt). „None“ → **4+**; „Infrequent/Mild“ → Apple computes a higher rating
  (9+). Answer it as you judge it – the rating only limits the store's parental controls. Everything else is „None“
  / „No“: no unrestricted web access, no content shared with others, no gambling, contests, purchases or ads.
- Privacy policy URL: https://thezieger.github.io/rogue-adventures/datenschutz.html
- Content rights: no third-party content (sounds are CC0, fonts SIL OFL – listed in `docs/sounds/SOURCES.md`, `docs/fonts/`).

**App Privacy („nutrition label“)**
- Data collected: **yes** → User Content → „Other User Content“ (the feedback message and the version number).
  Use: App Functionality (feedback). Linked to the user: **no**. Used for tracking: **no**.
- Everything else (identifiers, usage data, diagnostics, location, contacts): not collected.
- Encryption: the build declares `ITSAppUsesNonExemptEncryption = NO` (only HTTPS), so no export compliance prompt.

**Version page (de-DE)** – texts can be shared with the Play listing in `../android/README.md`:
- Name (max 30): `Lernquest – Klasse 1 bis 3`
- Subtitle (max 30): `Jede Attacke ist eine Aufgabe`
- Promotional text (max 170, can change without review): `Neu: Klasse 1 und 2, Deutsch, Musik und Englisch.
  Vorlesen, Stempelheft, Wochenziele und ein Duell für zwei Kinder an einem Gerät.`
- Description: the full description from `../android/README.md`.
- Keywords (max 100, comma-separated, no spaces needed):
  `Grundschule,Mathe,Deutsch,Einmaleins,Rechnen,Lesen,Schreiben,Sachkunde,Englisch,Klasse 1,Lernspiel`
- Support URL: https://github.com/theZieger/rogue-adventures (or a page with a contact address)
- Screenshots: `store/screenshots/iphone-*.png` (6.9″ display) and `store/screenshots/ipad-*.png` (13″ display).
- Review notes: „Lernspiel ohne Konto. Elternbereich: Knopf ‚Eltern‘ oben rechts (keine PIN voreingestellt). Das
  Feedback-Formular im Elternbereich (Einstellungen → App) sendet an ein Google-Formular.“

**Review risks**
- Guideline 4.2 (minimum functionality) rejects apps that are only a website in a frame. Lernquest is bundled, works
  offline and is a complete app, which is the usual way such apps pass. If a reviewer still objects, reply in
  Resolution Center describing the offline content (7 800+ tasks, parents' area, saves on the device).
- Guideline 5.1.1: the privacy policy must be reachable in the app – it is (title screen and parents' area).
